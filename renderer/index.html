使用 Wargaming 账号登录

需先在 Wargaming 开发者平台（developers.wargaming.net）注册应用获取 Application ID，并在应用设置中把 Redirect URI 填为http://localhost:8765/callback

使用 Lesta 账号登录（俄服）

俄服（Lesta）账号与 Wargaming 账号相互独立。请在 developers.lesta.ru 注册应用获取 Application ID，并将 Redirect URI 填为http://localhost:8765/callback

登录基于 Wargaming / Lesta 官方 OpenID，令牌由官方签发，仅存储在本机，用于访问战绩与账号信息。
